# 剧情演绎引擎与 VN 演出规范

配套《DESIGN/story.md》V7.2（剧情唯一来源）与《DESIGN/gameplay-v2.md》V7.2（玩法规则）｜2026-10-31｜读者：程序、UI、美术、测试

## 0. 定位与铁律

本文档是**演出引擎规范**：定义视觉小说（VN）呈现形式的实现规格——背景图 ＋ 底部对话框、立绘对话、剧情选项弹窗、段落卡、幕内气泡与道具插帧；并说明三幕巡检里检查面板、取证相机与无人机的演出边界。

**剧情、台词、分支、推进一律以《DESIGN/story.md》V7 为唯一来源**，本文不自创任何剧情内容。

四条铁律：

1. **不泄露答案**——背景图、立绘、道具插帧不得呈现任何变体特有现象或判定结论（story.md §6 分支结构、gameplay-v2 §9 防剧透）。观察结论必须按当前变体生成，不得使用静态“异常描述”兜底。
2. **不替玩家做决策**——取哪件工具、测哪个点、如何处置全部留在 3D 场景与检查面板；VN 选项窗只承载 story.md 登记的剧情选项 **CHO-PRO-01**（整改时限政策）。
3. **主角不出境**（story.md §3 人物）——陆川无立绘、无形象；台词与独白以名牌＋文本呈现；涉及主角的画面用道具插帧或记录仪/无人机画面转译。
4. **全部过场可跳过，选项必选**——跳过不扣分、不影响判定；遇 CHO-PRO-01 必须停下等待玩家选择（政策 flag 写入存档）。

## 1. 呈现形态的实现规格

V7 三幕使用五种形态：VN 对话、幕内气泡/电话、段落卡、检查面板、结局结算页。story.md 各幕标注“VN / 3D / 气泡 / 段落卡 / 插帧”，本节定义实现规格。

### 1.1 VN 对话（背景图 ＋ 底部对话框）

```
┌──────────────────────────────────────┐
│            背景图（全屏 cover）         │
│              （立绘区）                │
├──────────────────────────────────────┤
│ 【陈立群】 「今天三处，走一圈。」       │
│                            ▼         │
└──────────────────────────────────────┘
```

- 背景图全屏铺满（cover），底部对话框宽 `min(100%, 960px)` 居中，高约视口 22%。
- 文本逐字输出：默认 32 ms/字；点击 / 空格 = 补全当前行，再点 = 下一条。
- 名牌在对话框左上角，梯形切角样式（复用 HUD `clipPath` 视觉语言）。
- 独白以斜体呈现。
- 只有**序幕**和**结局**使用 VN 层；幕内事件台词走气泡/电话，不打断巡检。

### 1.2 立绘展示（人物对话）

- **单人对话**：说话者立绘居中，底边贴对话框顶部，高约视口 65–75%。
- **多人在场**（最多三人）：左/中/右站位；当前说话者亮度 100% 且上移 8 px，非说话者压暗至 40%。
- 立绘切换姿态（normal / serious）时交叉淡入淡出 200 ms。
- **陆川永不出现立绘**（铁律 3）：其台词只有名牌＋文本。
- 电话/对讲角色（王振、周敏）：对话框左侧头像圆标 ＋ 电流纹音效，无立绘。
- 序幕立绘：陈立群（center）、王振（left）、赵志远（right）。

### 1.3 选项弹窗（剧情走向选择）

```
┌──────────────────────────────────────┐
│           背景图（停格）               │
│       ┌────────────────────┐         │
│       │ 怎么收口？            │         │
│       │ ① 能晚上补的先补…   │         │
│       │ ② 今天必须闭环…     │         │
│       └────────────────────┘         │
└──────────────────────────────────────┘
```

- 对话推进到选项行时文本停格；选项弹窗居中，背景半透明遮罩。
- 选项 2–4 个；数字键 1–4 快捷选择；悬停高亮 sky-400。
- **必选不可跳过**（铁律 4）。
- 选择后写入 `pro_policy`（`defer` / `today`），随存档保存；V7 不再有第五幕复核面板，政策只保留在记录与终局文案中。
- 选项数据来自 story.md §6 登记；引擎不做任何玩法判断。

### 1.4 段落卡（黑屏过场）

- 黑底深色渐变，左上显示 `ACT 0X · 下一幕`；主体为下一幕标题、时间/地点与范围一句（取自 `ACT_TASK_CARDS`），底部为 4 s 进度线。
- 主按钮 `进入第X幕`（带箭头）可提前进入；不点击则 4 s 后自动进入。用于：序幕 → 第一幕、第一幕 → 第二幕、第二幕 → 第三幕。
- V7.2 结局不使用黑屏段落卡：先进入与序幕同规格的 GOOD / END VN，VN 读完后进入结算页（见 §1.6）。

### 1.5 游戏内对话（宽屏电影层，与序章共用对话框）

- 台词来自 `ACT1_LINES`，由规则层按事件排队（`pendingLines`），一次一条。
- **进入电影层**：上下黑边（letterbox）、隐藏全部游戏 HUD、冻结移动/鼠标视角与其他按键；玩家只可点击任意处或按 `Space / Enter` 推进。
- **推进规则**：一次输入只消费当前一条；队列未清空时保持电影层，清空后自动退出、恢复 HUD 与控制。系统记录、电话、对讲、独白都遵守同一规则，不再自动消失。
- **触发方式**：第二幕走到南区 `MEMBER_01/02` 工作人员附近（半径 6 m）自动排队 A2-00~05；第三幕进入施工区、接近安全警示牌（半径 8 m）自动排队 A3-00~03。触发不需要点击；进入电影层后才由点击/空格推进。
- 资料弹窗/检查面板打开时不进入电影层；关闭后继续播放队列。
- **每幕结束前必须先清空当前聊天队列**，由 `StoryLayer` 的 act-complete 阻塞与 `storySession` 的 reducer guard 双重保证。
- 底部对话框与序章共用 `src/components/VnDialogueBox.tsx`（由 `VnChrome` 提供角标与头像兜底）：DATA ID、说话人名/职务、频道标签、正文、Space/鼠标确认提示完全一致；游戏内不再单独维护一套聊天气泡样式。
- 对话层 z-index 40，位于 HUD 之上、模态层之下；不遮挡中间场景画面（黑边只压上下边缘）。
- 序章使用同一组件的背景/立绘/选项层；游戏内只复用对话框，3D 场景作为电影背景。

### 1.6 结局 VN 与结算页（V7.2）

- 第三幕完成、聊天队列清空后进入 `ending-good` / `ending-end` VN 场景；与序幕共用 `VnOverlay` 和 `VnDialogueBox`，背景分别为 `bg-site-dusk` / `bg-meeting-night`，支持跳过。
- 结局 VN 的立绘：陈立群（中）、王振（左）、赵志远（右）；END 的周敏走电话头像，陆川不出镜。
- VN 读完后进入**全黑屏安全推演结果页**，不使用浮动 HUD/卡片弹窗。
- GOOD：显示“本周工程和设备都稳定安全进行，得到总监的褒奖，请继续努力！”，只保留推演评分。
- BAD/END：从事故池随机抽取一起事故，展示事故经过与“免去陆川专业监理工程师（安全）资格”的通知书；不列明细漏项。
- 按钮：`重走全程`（清档、重置玩家到第一幕起点、重新抽变体）与 `返回标题`，全黑页底部排版。
- 不接入复核/上报 UI；处置等级不参与结局判定（只看隐患是否定级到 P1 及以上并取证）。

### 1.7 检查面板与取证相机

- 检查面板为三步式：观察（必做）→ 逐项检测（全部完成）→ 处置定级（P0 正常记录 / P1 及以上取证）。
- 定级不即时提示对错；选错仪器才扣 1 次检查机会（−8 分）。
- **取证**由独立的离屏相机渲染 480×270 画面，叠加区域、读数、时间与坐标水印；不遮挡主视角。
- 第三幕人员防护点位（`a3-hardhat`）要求无人机视角：地面按 G 被拒绝并提示“升空后用无人机取景取证（U）”；在无人机视角按 G 时，取证相机取无人机当前位置与目标点构图，记录无人机坐标。
- 无人机不得飞越运行间隔/运行主变正上方：进入禁飞区立即红色警告，扣 8 分并消耗 1 次检查机会（story.md §11）。

### 1.8 道具插帧

- 全屏特写图（16:9），替代镜头剪辑；来源为 story.md §12。
- 本期已接入：巡检路线图（PR-01，序幕）。
- 预留：红外对比（第一幕反馈）、无人机取证缩略图、记录仪截图（END 终局）。
- 插帧期间对话框保留（承载画外音与独白）；每帧停留 = 台词行进完成 ＋ 600 ms。
- **无人物原则**：不得出现人物形象与手部以外的身体部位。

## 2. 数据结构与解释器

```ts
export type VnSpriteSlot = 'center' | 'left' | 'right';
export type VnSpritePose = 'normal' | 'serious';

export interface VnCastMember {
  charId: string;
  pose: VnSpritePose;
  slot: VnSpriteSlot;
}

export interface VnLine {
  id: string;                     // story.md 台词 ID：PRO-01 / A1-00 / A3-01 ...
  speakerId: string;              // 'chen' | 'wang' | 'zhao' | 'ma' | 'luchuan' | 'system'
  text: string;
  channel?: 'radio' | 'phone';    // 电话：头像圆标，无立绘
  monologue?: boolean;
  propFrame?: string;             // 'prop-route-map' | ...
  next?: string;                  // 显式跳转；缺省按数组顺序
}

export interface VnChoice {
  id: string;                     // CHO-PRO-01
  prompt: string;
  options: Array<{ text: string; subText?: string; nextLineId: string; flag: string }>;
}

export interface VnScene {
  id: string;                     // 'prologue'
  bg: string;
  cast?: VnCastMember[];
  lines: Array<VnLine | VnChoice>;
  skippable?: boolean;
}
```

解释器 reducer（纯函数，`src/game/vn.ts`）：

```ts
type VnAction =
  | { type: 'advance' }
  | { type: 'choose'; optionIdx: number }
  | { type: 'skip' }
  | { type: 'auto'; on: boolean }
  | { type: 'fast'; on: boolean };
```

- `advance` 先补全逐字输出，再进入下一行。
- `choose` 只在当前行是 VnChoice 时有效；选项窗出现时 `advance`/`skip` 无效（铁律 4）。
- `skip` 遇 VnChoice 必停；序幕 `skippable=false`，只允许 Esc 跳至段落卡。
- flags 以 `key=value` 字符串写入（`pro_policy=defer|today`）；履历上限 30 条。

## 3. 集成与状态流

### 3.1 状态机（V7 三幕）

```
title ─▶ 序幕 VN（含 CHO-PRO-01）─▶ 段落卡 ─▶ 第一幕
第一幕 ─▶ 段落卡 ─▶ 第二幕 ─▶ 段落卡 ─▶ 第三幕
第三幕完成 + 聊天清空 ─▶ GOOD / END VN ─▶ 结算页
幕内失败：ACT FAILED 页（无 VN）─▶ 重来本幕（不设分数上限，不重播过场）
```

- 幕间只走段落卡，无复核/上报 UI；一幕的检查点全部处置完成 → 1.2 s 后自动进入下一幕段落卡。
- 新增覆盖层状态 `vn: { sceneId; index; revealed; flags; history; auto; fast } | null`；VN 期间冻结玩家输入与计时，3D 渲染保持。
- VN 层 z-index 25；段落卡 / 任务卡 / 检查面板 z-index 30–50；淡入淡出 400 ms。
- 幕内事件台词不进 VN 层，走场中气泡 ＋ 电话小窗。

### 3.2 复用现有代码

| 现有资产 | 复用方式 |
| --- | --- |
| 模态框视觉体系（sky-400 边框、#0a1322 底、clipPath 切角） | 对话框、名牌、选项窗、结算页 |
| `sound.ts` | radio-in、page-turn、shutter |
| `SubstationMinimap` 范围圈 | 段落卡后的区域指引 |

| 3D 光照预设 | 背景图同源光照，避免过场与场景跳变 |

## 4. UI 规格

- 对话框：`rgba(7,16,30,0.92)` ＋ `border sky-400/50` ＋ 顶部 2 px 强调线。
- 控件条：`[跳过 ▶▶] [履历 ▣] [自动 ▶]`；设置面板增加“文本速度 / 自动播放延迟”。
- 键位：`Space/Enter/左键` 前进；`1–4` 选项；`Ctrl` 快进；`Esc` 呼出“继续 / 跳过整段”。
- 履历：最近 30 行，可滚动；正文 ≥16 px。

### 5.3 单点交互流程

```
靠近点位 → F 打开检查面板
  → 步骤 1 观察（必做，完成后才解锁检测）
  → 步骤 2 逐项检测（列出该点位全部测点，必须全部完成）
  → 步骤 3 处置定级（选一个等级，等级即结论）
         ├─ P0 正常记录 → 直接处理完成（不取证、不整改）
         └─ P1 及以上 → 拍照取证 → 处理完成
  → 本幕所有点位“处理完成”后，自动进入下一幕场景卡
```

- 观察与检测是处置的前置条件；未完成时处置按钮禁用。
- 处置不提示正确性、不提示轻重，两个分支都可以选；系统不评价，结算只在第三幕结束时进行。
- **只有检测时选错仪器会扣检查机会**（−1）；机会耗尽 → 本幕失败重来。
- 测点选错（工具对、点位不对）只扣分，不扣机会。

### 5.4 处置梯度（按责任主体分两套）

安全监理的法定手段只对**施工单位**有效；运行设备缺陷由**运维单位**处理，监理只发现、记录、通知并跟踪。

**A. 施工安全监理处置 `construction`**

| 等级 | 处置 | 适用情形 |
| --- | --- | --- |
| P0 | 记录·提醒 | 文明施工轻微瑕疵 |
| P1 | 口头要求·当场整改 | 一般隐患，施工单位可立即消除 |
| P2 | 监理通知单·限期整改 | 一般隐患，需时间整改 |
| P3 | 立即停止该作业 + 建议暂停令 | 重大隐患 |
| P4 | 报告建设单位 | 拒不整改 |

**B. 运行设备缺陷处置 `equipment`**

| 等级 | 处置 | 适用情形 |
| --- | --- | --- |
| P0 | 记录归档 | 运行正常或仅外观轻微瑕疵 |
| P1 | 一般缺陷·报缺陷单 | 结合计划检修，不需停运 |
| P2 | 严重缺陷·限期停运处理 | 报运维与调度，转移负荷或安排停运 |
| P3 | 危急缺陷·立即申请停运 | 立即报调度，运维到场处理 |

判据：DL/T 664——δt ≥ 35% 为一般缺陷；热点 80~110 ℃ 或 δt ≥ 80% 为严重缺陷；热点 > 110 ℃ 或 δt ≥ 95%（且 > 80 ℃）为危急缺陷。

### 5.5 工具不提示原则（硬规则）

任务卡、HUD、NPC 台词、台账与交互标记中不得出现工具名或“该用某件工具”的暗示；背包与检查面板按设计展示工具本身除外。

## 10. 结局：GOOD / END

第三幕完成、且当前聊天队列清空后，进入与序幕相同的 **VN 结局**；VN 结束后进入**全黑屏安全推演结果页**（不是浮动 HUD 弹窗），不再进入复核面板。

| 结局 | 条件 | VN 场景 |
| --- | --- | --- |
| **GOOD** | 三幕全部完成，**所有发现的隐患**（含一般隐患）都定级到 P1 及以上并附现场证据闭环，且总分 ≥ 80 | `ending-good`（`bg-site-dusk`）：陈立群、王振、赵志远在场，陆川报告闭环，陈立群收束“监理的活是让问题有人负责”。 |
| **END · 事故责任** | 任一发现的隐患被记为 P0 正常记录放过（未定级取证），与总分无关 | `ending-end`（`bg-meeting-night`）：事故调查夜会，陈立群追问漏项，周敏电话补一句通知记录缺失，陆川列出漏项。 |
| **END · 延误工期责任** | 隐患全部闭环，但总分 < 80（多处置、处理过当、处置不到位导致扣分） | `ending-delay`（`bg-meeting-night`）：工期问责会，陈立群追问工期，陆川承认处置过当，按延误工期责任处理。 |

- 结局 VN 与序幕共用 `VnOverlay` / `VnDialogueBox`，支持跳过；跳过或读完后进入全黑结果页。
- **评分**：三幕共用一条总分，从 100 起累计扣分，不再按幕单独评分、不再取平均；结果页只显示这一条总评分与 80 分及格线，并保留逐幕复盘明细。
- **处置判定**：幕内不提示对错，幕结算时统一判定——无隐患点位却取证处理（多处置）、处置等级高于标准（处理过当）、等级低于标准（处置不到位），每个检查点 −8 分。
- **未闭环隐患**：每项 −25 分，因此事故责任结局的总分必然低于 80。
- 结局只看“发现的问题是否全部闭环”；处置等级不影响结局判定，只影响扣分与记录内容。
- 幕内不做任何对错提示；结果页用随机事故和问责通知书作为推演后果，逐幕复盘列出隐患、处置与扣分明细。

## 11. 失败、复盘与重来

- 选错仪器每次 −1 次检查机会；机会耗尽 → 总监约谈 → 重来本幕（继承上一幕总分，不设重走分数上限，不重播过场）。
- 红线：伪造记录、代签、删除记录仪影像、未确认安全措施进入运行区 → 立即失败。
- 无人机违规：飞越运行间隔正上方或站外导线 → 扣分并消耗 1 次机会。
